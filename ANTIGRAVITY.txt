Despliega este proyecto terminado de Seguros KR usando el proveedor y las credenciales que ya tengo configurados en este entorno. Conserva el diseño, el logo KR geométrico y el contenido existente. Es una web estática: publica el contenido de dist/ en la raíz del alojamiento; no necesita instalación ni compilación. Revisa la configuración disponible para identificar el proyecto de destino y evita crear recursos duplicados. Si hay varios destinos posibles, pregúntame cuál usar. Antes de publicar, configura la URL real con node scripts/configurar-dominio.mjs URL_REAL. Si la URL solo se conoce después del primer despliegue, actualízala y vuelve a desplegar. No expongas credenciales en archivos ni en logs. Comprueba la URL final, carga de imágenes y CSS, menú móvil, enlaces tel, directorio médico y enlaces WhatsApp. Devuélveme la URL publicada y cualquier paso pendiente de dominio o acceso.
